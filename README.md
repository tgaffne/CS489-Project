# CS489-Project

Title: Fitness Tracking System
Team Members: Aidan DeMuth, Tommy Gaffney

Description:
Our group wishes to create a wearable fitness tracker capable of collecting and exporting GPS data, heart rate/blood, and oxygen data with a focus on long-distance outdoor exercise. The device will be controlled by a microcontroller and send data over bluetooth to a user’s phone. The user will be able to view the GPS data overlaid on a map to track the route they took while exercising. A major consideration we have while designing the device is scale since we want to ensure it's small enough to be worn comfortably.

Components:
Microcontroller - ESP32 Dev Board / ESP32 DevKitC
Battery - Single‑cell LiPo battery
GPS module - u‑blox NEO‑6M GPS module breakout
HR module - MAX30102
Storage for GPS data - SD card
LED to display when/if the device is tracking
